"Aldar Kose"

🌟 О проекте

Приложение для кафе "Aldar Kose" и его службы доставки еды.

🧩 Приложение разработано с использованием React и TypeScript, фреймворком Next.js, реализовано с применением серверного рендеринга (SSR), что обеспечивает оптимальную производительность, улучшенную SEO-оптимизацию и повышенную скорость первоначальной загрузки страниц.

📦 Чем я занимался в проекте?
1. Оформление заказа:
- Создал компонент, страницу, маршрут формы заказа
- В форме заказа создал вводы - имя, адрес, коментарий
- Использовал для валидации данных zod и zodResolver и toaster для вывода информации
- Далее связал с товарами в корзине, и типизировал все
2. Фотогалерея:
- Создал страницу, маршрут фотогалереи, ссылка в навигации
- Использовал библиотеку Yet Another React Lightbox и его плагины для создания скролл-галереи
- Временно получение изображений происходит вручную, в будущем будет утилита для получения данных с сервера
- Сделал мобильную и десктопные версии более адаптивными
3. Карта:
- Создал компонент, страницу, маршрут карты, отображение на главной странице
- Интеграция Яндекс карты с помощью React Yandex Maps
- Кнопки для переключения на кастомные маркеры обозначения местоположения кафе
- location.type.ts - типы для данных о местоположении
