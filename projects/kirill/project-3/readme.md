# Rento TG API

**Ссылка на репозиторий:** [TOO-MIRcode/rento-tg-api](https://github.com/TOO-MIRcode/rento-tg-api)

## Описание проекта

Rento TG API — это веб-приложение, созданное для помощи риэлторам в размещении и продаже жилой недвижимости: квартир, домов и другой жилой площади. Проект предоставляет удобный и быстрый интерфейс для подачи и управления объявлениями.

## Технологии

Проект построен с использованием современных технологий фронтенда и инструментов:

- **React.js** — библиотека для создания пользовательских интерфейсов.
- **TypeScript** — статическая типизация для JavaScript.
- **Sass** и **Tailwind CSS** — для стилизации и адаптивного дизайна.
- **Vite** — современный инструмент сборки для быстрого запуска и разработки.
- **Node.js** и **Babel** — для серверной части и транспиляции кода.
- **Axios** — для работы с HTTP-запросами.
- **React Query** — для управления состоянием данных и кэшированием.

### UI Toolkits

- **Shadcn** — набор готовых UI-компонентов.
- **Shadcn Form Builder** — инструмент для создания форм.
- **Lucide-react** — иконки в стиле Lucide для React.

## Возможности

- Размещение объявлений о продаже/аренде жилья
- Удобный интерфейс для риэлторов
- Работа с формами и фильтрами через UI-компоненты
- Адаптивный и современный дизайн
