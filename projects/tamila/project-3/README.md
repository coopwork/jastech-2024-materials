# Gormolzavod

**Ссылка на репозиторий:** [TOO-MIRcode/dairy-client-react](https://github.com/TOO-MIRcode/dairy-client-react)

## 🥛 Описание проекта
Веб-приложение разработано для сайта [gormolzavod.kz](https://gormolzavod.kz/) — официального портала Городского молочного завода (г. Кокшетау, Казахстан). Сайт предназначен для представления продукции компании, новостей, партнёров, истории и контактной информации.

Проект ориентирован на повышение узнаваемости бренда, улучшение коммуникации с клиентами и создание современной, адаптивной онлайн-платформы.

## 🌐 Основные разделы сайта
- Каталог продукции (молоко, кисломолочные изделия, масло, мороженое и др.)
- Информация о компании и её достижениях
- Новости и события
- Партнёры и сертификаты
- Контактные данные и карта магазинов

### 📦 Используемые технологии
- **React.js** — библиотека для построения пользовательских интерфейсов  
- **Vite** — современный сборщик
- **TypeScript** — статическая типизация для повышения качества кода
- **Axios** — HTTP-клиент для запросов к API
- **React Query** — управление состоянием и кэширование данных
